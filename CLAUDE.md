# schedule-buttons-app

Phone app for private smart home. Controls devices over BLE (`schedule-power-board` firmware).
Workspace overview + BLE/proto contract: `../CLAUDE.md`.

## Stack
- Expo SDK 57, React Native 0.86, React 19.2, TypeScript (strict), Expo Router. Package manager: yarn (classic).
- Pinned to SDK 57 for Gradle 9.3.1 (machine standard). SDK 58 / RN 0.88 uses AGP 9.2.1, which needs Gradle >= 9.4.1. Don't upgrade without asking.
- `react-native-ble-plx` (config plugin in `app.json`). Protobuf: ts-proto output + `@bufbuild/protobuf` runtime.
- State: React context (`DeviceProvider`) + hooks. No Redux.

## Layout
```
src/app/           routes only: _layout (Stack + DeviceProvider), index (scan), device (profile router)
src/ble/           constants (UUIDs, MTU 185, 128 B frame, 3 s timeout), base64, codec (encode/decode, ErrorCode text),
                   pending (seq alloc + reply map, pure), client (ble-plx connect/write/notify, serial queue), manager (scan, perms)
src/proto/         GENERATED by `yarn proto`, committed. Do not edit.
src/devices/       DeviceContext (connect flow: GetInfo -> SetTime -> GetStatus, latest Status), useSchedules,
                   schedules.ts / buttons.ts / scroll.ts (pure helpers)
src/components/    ui primitives, DeviceHeader, ScheduleSection (list + editor), *Panel per Profile
```
Pure logic (`src/ble/{base64,codec,pending}.ts`, `src/devices/schedules.ts`) has no ble-plx import; tests in `__tests__/`.

## Proto
- `yarn proto` = `buf generate ../schedule-power-board/proto --template buf.gen.yaml` (npm `@bufbuild/buf` + `ts-proto` plugin, no protoc).
- ts-proto opts: `esModuleInterop, forceLong=number, oneof=unions, outputServices=false, outputJsonMethods=false`.
- Regenerate + commit `src/proto/` after every proto change.

## BLE
- Native module: not in Expo Go. Dev build: `npx expo run:ios|android` or `eas build --profile development`.
- Permissions via `app.json` plugins only. Never edit `ios/`/`android/` (CNG, gitignored).
- Requests serialized (one in flight). `seq` 1..2^32-1; `seq 0` = unsolicited Status.

## Commands
```bash
yarn install
yarn proto                  # regenerate src/proto from firmware repo
yarn android                # expo run:android: prebuild + Gradle build + install on device/emulator
yarn ios                    # expo run:ios
yarn start                  # Metro only, for an already installed dev build
npx tsc --noEmit
npx expo lint
yarn test                   # jest-expo, pure logic only
npx expo-doctor
npx expo install <pkg>      # always, instead of yarn add
```
